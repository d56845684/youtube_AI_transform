FastAPI + PostgreSQL JWT Auth Google Meet / VOOM

Language Tutor Marketplace

讓學生購買課堂點數、預約老師時段，老師維護可教時間，並自動生成線上會議連結的教學平台。

啟動 docker-compose 後，前端由 Nginx 提供，後端 API 與資料庫直接串接。

API Quick Start

  1. 註冊 /auth/register（角色 student 或 teacher）。
  2. 登入取得 JWT /auth/token。
  3. 教師建立時段 /teachers/availability，學生查詢 /teachers/<id>/availability。
  4. 學生下訂單 /orders、用點數預約 /bookings 並指定 Google Meet / VOOM。
