Language Tutor Marketplace

Roles

  • Students: purchase lesson credits via /orders and reserve available time slots with teachers.
  • Teachers: publish availability through /teachers/availability and receive bookings.

API Quick Start

  1. Register users via /auth/register (role is student or teacher).
  2. Obtain JWT with /auth/token using your email and password.
  3. Teachers create availability windows; students fetch them via /teachers/<id>/availability.
  4. Students create bookings through /bookings specifying platform (Google Meet or VOOM).

Dockerized Stack

  • Backend: FastAPI + SQLAlchemy with JWT auth.
  • Database: PostgreSQL with primary and foreign keys linking orders, bookings, users, and availabilities.
  • Frontend: this static landing page served by Nginx.

Run the stack with docker-compose up --build and open http://localhost:8080.
