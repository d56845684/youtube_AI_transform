FastAPI + PostgreSQL JWT Auth Google Meet / VOOM

Language Tutor Marketplace

讓學生購買課堂點數、預約老師時段，老師維護可教時間，並自動生成線上會議連結的教學平台。

啟動 docker-compose 後，前端由 Nginx 提供，後端 API 與資料庫直接串接。

API Quick Start

  1. 註冊 /auth/register（角色 student 或 teacher）。
  2. 登入取得 JWT /auth/token。
  3. 教師建立時段 /teachers/availability，學生查詢 /teachers/<id>/availability。
  4. 學生下訂單 /orders、用點數預約 /bookings 並指定 Google Meet / VOOM。

商業邏輯狀態

  • ✓學生下訂單產生課堂點數，並可透過 UI 及 /bookings 預約老師空檔。
  • ✓教師填寫可教學時間 /teachers/availability，等待學生預約。
  • ✓預約時指定平台（Google Meet / VOOM）後自動生成會議連結。
  • ✓資料庫模型涵蓋訂單、上課記錄、會員、優惠碼欄位、預約紀錄與教室預約狀態。

學生預約流程

教師可教時間

教師透過表單填寫可教學日與時間，系統會同步到資料庫的 teacher_availabilities 表，學生查詢後直接下單預約。

POST /teachers/availability JWT 保護

資料庫設計（重點表）

資料表 用途 關聯
users 學生 / 教師會員，角色分離 與 orders、teacher_availabilities、lesson_bookings 連結
orders 紀錄訂單金額、課堂點數、優惠碼 student_id → users
teacher_availabilities 教師可預約時段、預約狀態 teacher_id → users；與 lesson_bookings 一對一
lesson_bookings 學生預約紀錄，含會議連結與上課時間 student_id / teacher_id → users；availability_id → teacher_availabilities

所有表皆透過 SQLAlchemy 建立，支援主外鍵、預約狀態與時間戳記。

資料流對照

學生端

  • ✓購買點數：POST /orders
  • ✓查詢老師空檔：GET /teachers/{id}/availability
  • ✓預約並生成會議室：POST /bookings

教師端

  • ✓填寫教學時間：POST /teachers/availability
  • ✓查看預約：GET /bookings（教師角色過濾）
