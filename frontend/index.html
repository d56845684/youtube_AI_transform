學生登入 / 註冊 JWT 驗證 立即預約

線上家教預約中心

學生登入或註冊後，即可查看老師可預約時段，點擊選擇並送出課程預約，同時在同一頁面檢視自己的預約清單。

若未啟動後端，畫面會顯示示範資料，方便快速瀏覽流程。

使用步驟

  1. 註冊並登入取得 Token。
  2. 自動切換到「預約介面」。
  3. 點選老師時段，確認後送出預約。

登入

輸入帳密後即可取得 JWT Token，頁面會自動切換到預約介面。

註冊

建立學生帳號，立即登入並查看老師空檔。

選擇可預約時段

請輸入教師 ID 或使用示範資料

系統會依據教師 ID 呼叫 /teachers/{id}/availability，成功登入後會帶入 Token。

預約確認

點選左側任一時間後，會自動帶入預約表單。送出時會附帶登入 Token。
